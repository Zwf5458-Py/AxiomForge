---

## 1. Project Summary

DeepMind's **FunSearch** (*Nature 2023*) demonstrated that pairing Large Language Models (LLMs) with automated program evaluators can discover novel mathematical algorithms surpassing human-designed heuristics in extreme combinatorics (such as the Cap Set problem and Bin Packing).

However, current implementations remain largely proprietary, fragmented, or inaccessible to grassroots independent researchers. As an independent researcher without traditional institutional affiliation, I am building **an open, lightweight, and modular FunSearch framework** focused on:
1. Solving open combinatorial bounds (specifically Cap Set problem in $\mathbb{F}_3^n$ and Ramsey-type graph problems).
2. Incorporating test-time compute, evolutionary island selection, and cost-effective local/open-weight LLMs (DeepSeek-R1, Qwen-2.5-Coder).
3. Providing full verifiable Proof-of-Work (PoW) via public GitHub repositories and reproducible evaluation sandboxes.

---

## 2. Why This Matters & Theory of Change

- **Democratizing Mathematical Discovery**: High-end AI-for-math research should not be restricted to trillion-dollar corporate labs. By releasing clean, minimal, yet effective evolution frameworks, we enable global researchers to run combinatorial experiments on modest budgets.
- **PoW vs. Credentials**: Traditional academia filters candidates by diplomas rather than executable code. This project serves as a clean demonstration of the "Proof-of-Work" paradigm in mathematical research.
