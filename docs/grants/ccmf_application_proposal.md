## 1. 执行摘要 (Executive Summary)

**MathGenesis** 是一套面向前沿科研、金融量化及物流运筹领域的“AI 辅助数学发现与组合优化平台”。本项目打破传统“大模型仅做文字生成”的局限，结合 DeepMind 最新前沿技术（FunSearch 程序演化搜索）与现代动力学系统数值模拟，通过大语言模型自主编写、评估、演化 Python 算法代码，在极高维离散数学空间（如 Cap Set 问题、装箱优化、图论极值）中寻找超越人类直觉的最优解。

同时，平台结合 WebGL 与 GPU 片元着色器，提供毫秒级动态数学可视化与算法演化追踪面板，形成“自动演化发现 + 可视化交互验证”的完整技术原型（Working Prototype）。

---

## 2. 行业痛点与解决思路 (Problem & Solution)

### 2.1 行业痛点
1. **传统数学与运筹搜索的“组合爆炸”**：极值组合数学（如高维 Cap Set、Ramsey 问题）与超大规模物流调度（Bin Packing）的搜索空间随维度呈指数级暴增，传统暴力搜索与线性规划在维度超过 10 时完全失效。
2. **符号直觉难以程序化**：人类数学家设计启发式算法（Heuristics）极其耗时且受限于三维直觉，缺乏能够在高维空间自动化变异与优化的智能工具。
3. **黑盒神经网络缺乏可解释性与严谨性**：端到端的神经网络在数学上常常产生“幻觉”，无法输出具备严格数学证明的代码和确定性结论。

### 2.2 MathGenesis 破局方案
- **代码演化即真理（Code as Hypothesis）**：让 LLM 生成的不是答案，而是“生成答案的程序”。通过沙箱自动化运行并评分，杜绝幻觉。
- **孤岛遗传进化算法**：采用种群进化与岛屿隔离机制，防止算法收敛到局部最优。
- **纯静态与轻量化部署**：前端基于 WebGL 实时投影高维离散点阵与动力学轨道，无需高昂的私有服务器部署成本即可为用户提供极佳体验。

## 3. 商业价值与变现模式 (Market & Business Model)

虽然是数学与算法研究起步，但该底层技术直接映射至数千亿规模的工业级组合优化市场：

| 应用场景 | 商业映射 | 变现模式 |
| :--- | :--- | :--- |
| **仓储与集装箱装箱 (Bin Packing)** | 物流、海运与电商货运体积利用率优化 | 算法授权费 / 运筹 API 订阅 (SaaS) |
| **量化高频交易与网络拓扑** | 衍生品定价空间探索、通信交换网络低延迟路由 | 定制化企业算法顾问 |

## 6. 六个月阶段性交付里程碑 (Milestones & Deliverables)

CCMF 资助款项分三次发放（首期 50%、中期 30%、结题 20%），对应以下严格交付物：

### 里程碑 1 (第 1 - 2 个月)：核心引擎与基准对齐
- **交付目标**：跑通 FunSearch 在 $\mathbb{F}_3^4$（4维空间）及 $\mathbb{F}_3^5$ 下的 Cap Set 自动化搜索。
- **交付物**：
  - 核心 Python 开源算法库（GitHub 仓库 + CI 测试通过率 100%）；
  - 首期研发报告与已验证的基准数据集。
- **款项释放**：首期拨款 HK$ 50,000 启动资金到账。

### 里程碑 2 (第 3 - 4 个月)：前端交互平台与算法泛化
- **交付目标**：将演化出的数学算法接入 Web 交互系统，并拓展至装箱问题（Bin Packing）。
- **交付物**：
  - 上线的 Web 演示平台（支持实时查看搜索日志与三维投影）；
  - 中期进度报告（Interim Report）并通过数码港中期评审。
- **款项释放**：中期拨款 HK$ 30,000 到账。

### 里程碑 3 (第 5 - 6 个月)：结题验收与产业化对接
- **交付目标**：在公开学术预印本（arXiv）或 GitHub 社区发布技术白皮书，冲击 Kaggle AIMO 竞赛榜单。
- **交付物**：
  - 完整商业计划终稿与结题技术报告（Final Report）；
  - 参加数码港孵化器计划（Cyberport Incubation Programme - 最高 50 万港元资助）的进阶申请。
- **款项释放**：尾款 HK$ 20,000 结题划拨。

## 7. 申请实操指南与资格落地策略

- **申请窗口**：数码港 CCMF 每年开放 3 个批次（通常为 4月、8月、12月 截止）。
- **身份方案 A（本人持有香港身份）**：可直接以个人身份（Individual）或合伙人身份在线提交。
- **身份方案 B（非香港永居/跨境申报）**：
  1. **合伙人机制**：在团队成员中吸纳一名持有香港身份证的合伙人（占股或项目主要申请人之一即可）。
  2. **注册香港公司**：无须香港身份即可在 1~3 个工作日内于香港注册设立有限公司，以香港公司实体名义申请（数码港完全接受全资控股的离岸/跨境创业者通过香港公司申报）。
